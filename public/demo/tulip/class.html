Kinder Class

3歳〜おおよそ小学1年生までを対象

このクラスでは、楽しく踊るをモットーに、柔軟性、音楽性、協調性、集中力を身に付けていくためのレッスンを行います。早い段階(3歳〜)から、音に合わせて全身を動かすことでリズム感を養うことができます。また、身体能力の向上につながり様々な分野での成長が見込めます。
(毎週金曜日16:15~17:00 西新スタジオ)

Primary Class

小学2年生〜おおよそ小学5年生までを対象

このクラスでは、基本的なバレエの動きを学びます。バレエの動きに大切な柔軟性も養いながら、正しい姿勢で踊れるように筋力トレーニングも取り入れています。小学4年生以上から履き始めるトウシューズに備え、正しい姿勢の理解、つま先を伸ばすことなど、より基礎的な理解を深めていきます。小学生以上のバレエ初心者にもおすすめのクラスです。
・毎週水曜日17:00〜 西新Ⅱスタジオ
・毎週金曜日17:15〜18:15 西新スタジオ
・毎週土曜日13:00〜14:00 西新スタジオ
（※水曜日クラスは週2回受講者のみ）

Intermediate Class

トウシューズを履いている年齢(おおよそ小学5年生以上)を対象

このクラスでは、バレエの発展的な動きに加え、ヴァリエーション(ソロ)を踊ることを目的としています。このクラスを受講する生徒は発表会に向けて、それぞれ好きなヴァリエーションに挑戦します。ヴァリエーションのみならず、トウシューズでのレッスンもしっかり行いますのでご安心ください。
(毎週土曜日15:00~16:30 大濠スタジオ)

大人クラス

大人からバレエを始めた方(初心者)を対象

まず、ゆっくりとストレッチから始まるので、心身ともにリラックスした状態からレッスンへとつなげます。音楽に合わせて優雅に踊る楽しさを皆さんで共有しています。
(毎週火曜日11:00~12:30 西新スタジオ)
