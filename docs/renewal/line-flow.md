# LINE公式アカウント 運用設計 — NEXT VALLEY

サイトの導線（無料診断オファー）と接続する、友だち追加後のメッセージと流れの設計書。
文面はすべてコピペでLINE Official Account Managerに貼れる形にしてある。

---

## 全体フロー

```
友だち追加
   │
   ▼
① あいさつメッセージ（自動・2通）
   │  「URLかお悩みを送るだけ」と案内
   │
   ├─ ユーザーがURL/悩みを送信 ──▶ ② 初回返信（手動・当日中）
   │                                    │
   │                                    ▼
   │                              ③ 診断結果＋改善提案＋概算見積もり（手動・2営業日以内）
   │                                    │
   │                                    ├─ 返信あり ──▶ ④ 相談・クロージング
   │                                    └─ 3日返信なし ─▶ ⑤ リマインド（1回だけ）
   │
   └─ 追加だけで無反応 ──▶ ⑥ 翌日フォロー（1回だけ）
```

**応答モードは「チャット」を推奨**（Bot応答ではなく手動返信）。
理由: 相談の入口なので、機械的な自動応答よりも「人が返してくれる」体験のほうが成約に直結する。自動化するのは①あいさつのみ。

## ① あいさつメッセージ（友だち追加時・自動）

LINE Official Account Manager → トークルーム管理 → あいさつメッセージ に設定。

**1通目**

```
友だち追加ありがとうございます！
NEXT VALLEY代表の倉林です😊

このLINEでは、
✅ 無料のサイト・集客診断
✅ HP制作、SEO・MEO、SNS運用のご相談
✅ AI活用・業務効率化のご相談
を受け付けています。

診断・提案・お見積もりまで全部無料です。
しつこい営業は一切しません。
```

**2通目**

```
🔍 無料診断のはじめかた

▼ ホームページをお持ちの方
今のサイトのURLをこのまま送ってください。

▼ サイトがない・悩みから相談したい方
「問い合わせを増やしたい」「AIで業務を楽にしたい」など、一言で大丈夫です。

セルフ診断を受けた方は
「診断◯点でした」と送っていただければ、
結果をもとに具体的な改善案をお出しします！
```

## ② 初回返信（手動・当日中を目標）

URLや悩みが届いたら、まず受領の返信。**診断が完成する前に、まず反応を返す**のがポイント（放置感を出さない）。

```
{名前}さん、ありがとうございます！

いただいた内容を拝見して、
・どこを直すと問い合わせにつながるか
・概算でいくらかかるか
をまとめてお返しします。

2営業日以内にお送りしますので、少しお待ちください🙏
```

---

## ③ 診断結果の送付（手動・2営業日以内）

構成テンプレート。**3つに絞る**（多いと読まれない）。金額は幅で提示。

```
お待たせしました！
{サイト名/お悩み} を拝見して、改善ポイントを3つにまとめました。

━━━━━━━━━━
📌 診断結果
━━━━━━━━━━

① {最重要の課題}
→ {何が起きているか＋どう直すか}

② {2番目の課題}
→ {同上}

③ {3番目の課題}
→ {同上}

━━━━━━━━━━
💰 概算お見積もり
━━━━━━━━━━
{例: ①②のみ → ◯万円〜 ／ まるごと改善 → 初期◯万円＋月額◯万円〜}

ここまでは無料です。
「もう少し詳しく聞きたい」「オンラインで話したい」など、お気軽にどうぞ。
もちろん、ここでお断りいただいても大丈夫です！

サービス全体と料金の一覧はこちらにまとめています📄
{service-overview.pdf を添付}
```

**※ サービス概要資料（service-overview.pdf）はこのタイミングで添付する。** 友だち追加直後の自動送付はしない（営業臭が強くなりブロック率が上がる）。ほかに送ってよいのは「料金を聞かれたとき」「商談後のフォロー」「紹介を頼まれたとき」。

## ④ 相談・クロージング（返信が来たら）

- 質問には24時間以内に返信
- 2往復以上続くようなら「15分だけオンラインで話しませんか？」とビデオ通話を提案（テキストより成約率が上がる）
- 提案受諾後は「ご依頼の流れ」（ご相談→提案→制作→公開・運用）を再送し、着手時期と必要素材を伝える

```
ありがとうございます！では進め方です。

1️⃣ 正式なお見積もり・スケジュールをお送りします
2️⃣ ご確認いただけたら着手します
3️⃣ 制作中もこのLINEでいつでもやり取りできます

まず、{必要な素材・情報} をお送りいただけますか？
```

## ⑤ リマインド（診断送付後、3日間返信がない場合・1回だけ）

**追撃は1回まで。** 「しつこい営業なし」の約束を守る。

```
{名前}さん、先日の診断はご覧いただけましたか？😊

ご不明点があればお気軽にどうぞ。
「今は検討だけ」でも全く問題ありません。

もし優先順位に迷われていたら、
「まずどれからやるべきか」だけでもお答えできます！
```

## 運用ルール

1. **返信SLA**: 初回反応は当日中、診断は2営業日以内（サイトで約束している「2営業日以内」と揃える）
2. **追撃は各1回まで**（⑤⑥）。それ以上は送らない
3. **診断は必ず「3つ＋概算」の型で**。長文になったら削る
4. **月次で見る数字**: 友だち追加数 ／ URL・悩み送信率 ／ 診断送付数 ／ 成約数（GA4の `line_click` と突き合わせる）
5. 通話・対面の約束は必ずLINE上でも文字で残す（言った言わない防止）

## ⑦ 無料プレビュー制作（/preview からの申込・毎月10社限定）

LINEで「プレビュー希望」が届いたら、以下を送る。**受付枠の管理**は `src/app/preview/page.tsx` の `REMAINING_SLOTS` を書き換えて公開（毎月1日に10へ戻す）。

**受付返信（5問）**

```
ありがとうございます！無料プレビュー制作を受け付けました。
下の5つに、分かる範囲で答えてください（箇条書きでOKです）。

1. 業種・サービス内容（例：整体院／工務店／英会話教室）
2. 地域（例：渋谷区／大阪府和泉市）
3. いちばん伝えたい強み・選ばれる理由
4. 好みの雰囲気（例：シンプル・高級感・親しみやすい）
   参考にしたいサイトがあればURLも
5. 写真・ロゴなどの素材の有無（なくてOK）

＋ 事業が分かるもの（店舗名・SNS・Googleマップ・既存サイトのいずれか）
　※ 本気でホームページを作る事業者様のための枠のため、確認させていただいています。

いただいてから3営業日以内に、トップページのデザイン案を
PC・スマホの画像でお送りします。
```

**確認（受付返信のあと・LP「For」セクションと同じ基準）**
- 3条件: ①事業の実態が確認できる ②決められる本人 ③本気で作る予定がある
- 対象外: 同業（制作会社・デザイナー・フリーランス）／参考資料・相見積もり目的／作る予定・予算がない／事業実態が確認できない
- 対象外と判断したら、制作に入らずに下記を送る:

```
ご連絡ありがとうございます。
無料プレビューは「これから本気でホームページを作る事業者様」に
毎月10社分だけお作りしている枠のため、今回はお受けできかねます。
（同業の方・参考資料が目的の方・制作予定が未定の方はご遠慮いただいています）

ホームページを作ることが決まりましたら、
その時にあらためてお声がけください。
```

**納品（3営業日以内）**

```
お待たせしました！{屋号}様のトップページ案です（PC・スマホ）。

このデザインで公開まで進める場合の目安は下記です。
・ホームページ制作：¥220,000〜（内容により変動／正式なお見積もりを先にお出しします）
・LP制作：¥110,000〜

「進めたい」でも「今回は見送り」でも、どちらでも大丈夫です。
直したい点があれば、1回まで無料で調整します。
```

**ルール**
- プレビューは**画像で渡す**（PNG。編集データ・コードは正式制作後）
- 追撃なし。返事がなければそのまま終了（⑤のリマインドも送らない）
- 「参考にしたいだけ」「同業」「事業実態が確認できない」と分かった場合は、上の定型文で丁寧に断る（本気で作る予定の事業者が対象）
- GA4: `/preview` からのLINEクリックは `line_click` の `source: preview` で識別
