## 2. 攻める順番（小さく勝ってから広げる）

1. **本庄市**（競合が少ない・地元出身という本物の理由がある）→ 3か月で1ページ目、半年で上位
2. **埼玉北部の市**（熊谷市・深谷市・本庄市・上里町など）→ 本庄で勝った型を広げる
3. **埼玉 ＋ 条件**（「埼玉 ホームページ制作 月額」「埼玉 ホームページ制作 教室」「埼玉 ホームページ 安い」など）→ 県全体の言葉より先に取れる
4. **埼玉 ホームページ制作**（県全体）→ 1〜3の積み上げで、半年〜1年かけて1ページ目

## 4. 信頼の裏付け（上位に出るための中身）

- **本庄・埼玉北部の実績を1件つくる**（いちばんの弱点）。本庄・児玉郡はメール営業をせず、しゅんがオフライン（紹介・対面）で1件目をつくる
- 実績ページ（/works）に、地域と業種を書き添える
- 代表のプロフィール（本庄市児玉町出身・2021年開業・代理店経由を含め100社以上）を、トップ・/honjo・記事の著者欄で統一
- お客様の声（Tulip・Rythmique Garden など）を、地域ページにも載せる

## 5. 外からの紹介（被リンク・掲載）

- **Web幹事**（登録済み）: 本庄市まとめ・埼玉県まとめ（https://web-kanji.com/posts/saitama）への掲載を依頼（文面は docs/seo/honjo/本庄市1位の進め方.md）
