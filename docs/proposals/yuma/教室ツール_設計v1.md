# 教室ツール 設計 v1（Yuma English House 向け・2026-09-22）

## 決めたこと

- 名前（仮）：**きょうしつノート**
- 最初の1社：Yuma English House（竹内様）。生徒約30人、個人経営、月次レポートと集客支援で信頼あり
- 作り方：案件ボードと同じ。1枚HTML＋スプレッドシート保存。スマホ優先。合言葉で入る
- 価格：月額11,000円（3か月お試し）。今の44,000円の集客支援に上乗せ

## 使う人の1日から決める（竹内様）

朝：今日のレッスンは誰と何時か → **今日の画面**
レッスン後：出欠を付ける。振替が出る → **出欠の1タップ**
月初：月謝の入金を確認して、まだの人に連絡 → **月謝の画面**
月末：領収書を出す、会計に数字を渡す → **PDFとCSV**
すきま時間：インスタの投稿を書く → **投稿文をAIで**

## 画面（4つだけ）

1. **今日**：今日のレッスン一覧（時間・生徒・場所）、出欠ボタン、今日やること（未入金の連絡、体験の返信）
2. **生徒**：名前、保護者の連絡先、コース、曜日、月謝額、入会日、メモ。生徒を開くと出欠と月謝の履歴
3. **月謝**：今月の「入金済み／未入金」一覧。未入金はタップで連絡文をコピー。領収書PDFを1タップ
4. **書く**：インスタ投稿文の生成（今週のレッスンの様子を一言入れると、投稿文＋ハッシュタグが3案出る）。メモ、ファイル（写真・PDF）もここ

設定：教室名・コース・月謝・振込先・利用規約PDF

## やらないこと（v1）

- Misoca、Coffesign、MoneyForward との自動連携（API契約と審査で数週間）。代わりに：領収書はPDF、会計はCSV書き出し、規約はPDFを保存して生徒画面から送る
- 保護者が自分で見るページ（v2。振替申請・欠席連絡はここに入れると一番効くが、先に先生側を固める）
- 決済（Stripeで月謝を取る）はv2

## 使いやすくするための決め

- 1画面1目的。開いたら「今日」しか出ない
- 入力は最小。生徒の登録は名前と曜日だけで始められる。あとから足す
- 月謝は「入金済み」を押すだけ。金額は生徒に紐づく
- ボタンは大きく、文字は16px以上、専門用語なし
- 消す操作は5秒だけ戻せる（案件ボードと同じ）

## 進め方

1. 竹内様に「月謝と出欠の管理、いま何でやっていますか？」を聞く（聞く文面は下）
2. 答えを見て、画面を1日で作る
3. 竹内様に1週間使ってもらい、直す
4. 3か月で形にして、DSP・Coloursに横展開
